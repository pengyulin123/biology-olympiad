# 生物竞赛作战台 · BioLab

面向全国中学生生物学竞赛（CHSBO / CNBO）的静态资源站。
纯 HTML + CSS + 原生 JS，**零依赖、零构建、可离线打开**。

---

## 一、这是扁平版

所有文件**平铺在根目录**，没有子文件夹，方便手机端一次性多选上传。

```
index.html  knowledge.html  guide.html  plan.html  drill.html
404.html    .nojekyll       README.md

bio.css                            全站样式
app.js  kg.js  drill.js  guide.js  edit.js

kg-index.js    索引（册→章→条目）      232 KB  首屏
kg-terms.js    2362 条术语              327 KB  首屏
kg-exam.js     真题命中（占位）
kg-texts.js    页面文案覆盖表

books-1.js     第 01–06 册正文         1139 KB
books-2.js     第 07–12 册正文         1247 KB
books-3.js     第 13–18 册正文          705 KB
```

**共 21 个文件。** 与标准版唯一的区别：18 册正文合并成 3 组（每组 6 册），
展开某册时下载它所在那一组（约 1.2 MB），而不是单独一册（约 200 KB）。
换来的是手机上传从 41 个文件降到 21 个。

首屏仍只加载 `kg-index.js + kg-terms.js + bio.css + 五个脚本` ≈ 700 KB。

## 二、知识库（4995 知识点 + 2362 术语）

数据由两份 PDF 脚本解析而成：
《生物竞赛知识点总纲·全十六册合集》（1641 页）与《生物竞赛名词索引》（128 页）。

| 标签 | 功能 |
|---|---|
| **总纲** | 18 册 → 688 章 → 4995 条三级目录树，按 ★★★ 筛选；点条目从底部弹出正文，可连翻上下条 |
| **术语** | 2362 条，中/英/释义三向搜索；每条后面的「出处」标签一键跳到总纲对应册章 |
| **闪卡** | 术语卡（正/背面）与知识点卡；**挖空模式**把正文里的术语变成 ＿＿＿ 让你补 |
| **重点** | 按册聚合 ★★★ 条目，点板块可筛选 |

### 闪卡三种用法

- 默认「术语卡」：正面中文术语，背面英文 + 释义
- 「知识点卡」：选册后生成，正面是条目标题，背面是正文
- 「知识点卡」+「挖空」：从正文里挖掉 2–3 个术语，先补再核对。实测 90% 的条目能挖出至少一个空，剩余 10% 自动退回普通卡片

「记住了」的卡片存入本机，不再出现。

## 三、错题本（drill 页）

每次提交判分，**答对 ≤3 个选项的题自动进错题本**，记录：题干、你的每个选项判断、正确答案、解析、关联知识点。

点「相关：光呼吸 →」跳到 `knowledge.html?q=光呼吸`，直接出检索结果。

## 四、关于「真题考频」

**尚未实现真实考频统计。** 原因：联赛真题存放在订阅类知识库中，导出接口返回
「订阅知识库查看完整内容」，无法取得原文做关键词匹配。

当前 `knowledge.html` 的「重点」标签用的是**总纲自带的 ★ 星级**（★★★ 共 3161 条），
这是原作者标注的联赛/省选高频，不等于真题统计。

### 如果你有真题 PDF，可自己生成

1. 把真题按年份放进 `exam/`（如 `exam/2024.pdf`）
2. 运行：

```bash
python3 build_exam.py          # → bio-lab/data/exam.js
```

3. 页面会在知识点条目上显示命中该考点的年份

`build_exam.py` 的做法：pdftotext 提取真题文本 → 用知识点词汇表（术语 + 标题片段）
逐条匹配 → 记录每年命中情况。它是**关键词匹配**，不是人工标注，结果只作参考。

换排版需改 `build_outline.py` 的正则。

## 八、编辑模式

点右下角 **✎** → 输入密码 `pengyulin` → 进入编辑模式。

### 能改什么

| 对象 | 操作 |
|---|---|
| 知识点 | 改标题 / 星级 / 正文；删除；底栏「＋条目」新增到指定册·章 |
| **章节点** | 每册底部「＋ 新增章」；每章右侧「✕」整章删除（连同其下所有条目） |
| 术语 | 术语列表每条末尾的「编辑」，改中文 / 英文 / 释义 |
| 页面文字 | 编辑模式下所有标题、段落、列表项都变成可编辑，点上去直接改 |

### 修改存在哪

**只存在你自己的浏览器里**（localStorage）。部署到 GitHub Pages 后：

- 你自己打开 → 看到的改动
- 别人打开 → 看到的还是原版

这不是 bug，是静态站点的物理限制。要让改动对所有人生效，走下面这条。

### 让改动真正上线

1. 编辑模式下点底栏 **导出** → 得到 `bio-lab-edits.json`
2. 把文件放到 `/sandbox/workspace/`，执行：

```bash
python3 apply_edits.py bio-lab-edits.json
python3 build_site_data.py
python3 build_standalone.py
```

3. 重新部署 `data/` 与 `index.html`

`apply_edits.py` 会把改动合并回 `datasrc/outline.json`，文案写进 `data/texts.js`（页面会自动读取）。

### 关于密码

**这不是安全措施。** 纯静态网页，密码写在前端代码里，任何人查看源码都能看到。
它只能防止你自己手滑改坏内容，挡不住懂技术的人。真正的权限控制需要后端服务器。

## 九、题目导入

练习页新增第三个标签「题库」，可以往里灌题。

### 两种导入方式

**① 粘贴纯文本**（最顺手，直接抄真题解析）

```
关于酶的叙述，判断正误。
A. 酶通过降低活化能加快反应 (T)
B. 绝大多数酶的化学本质是蛋白质 (T)
C. 竞争性抑制剂会改变 Vmax (F)
D. 所有酶的最适 pH 均为 7 (F)
解析：竞争性抑制剂只改变表观 Km。
```

题干一行 → A/B/C/D 四行 → 每项末尾标 `(T)` 或 `(F)` → 可选「解析：」一行。
支持中文括号 `（T）`、顿号 `A、`、以及 `对` / `错` 的写法。多题之间空一行，一次可粘一整套。

**② 选择 JSON 文件**

```json
[
  {
    "topic": "生物化学",
    "stem": "关于酶的叙述，判断正误。",
    "opts": [
      { "t": "酶降低活化能", "a": "T" },
      { "t": "多数酶是蛋白质", "a": "T" },
      { "t": "竞争性抑制剂改变 Vmax", "a": "F" },
      { "t": "所有酶最适 pH 为 7", "a": "F" }
    ],
    "exp": "竞争性抑制剂只改变表观 Km。"
  }
]
```

### 导入之后

- 新题和内置 12 题混在一起，判分规则完全一致
- 答错的照样进错题本，能关联知识点
- 「导出」可以存成 JSON 备份或发给同学
- 题目存在本机 `localStorage`，清浏览器数据会丢，建议定期导出
